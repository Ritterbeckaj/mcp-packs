Why deterministic

An agent asked for a SWOT will happily write four plausible quadrants. That output is unfalsifiable — you can't tell a real analysis from a convincing one. These tools compute the cross-mapping, rank the options, score the criteria, and hand back the same structure every run, so the reasoning is inspectable and the result is reproducible.
